# financeManager (archived)

Early scaffold of a personal finance manager: a Spring Boot backend and an Android client in Kotlin, both generated from project templates. It was not developed beyond the initial setup.

The idea continued as **My Wallet** — [Slamonu/financesDebian](https://github.com/Slamonu/financesDebian), a Spring Boot 4 / Java 21 web application with JWT authentication, Flyway migrations, invoice OCR and a full test suite.
